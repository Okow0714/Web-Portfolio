# Bridge rows to check

These 73 rows came from the MN -> English -> JP bridge, and their English carried **three
or more separate senses** -- so the pivot had a choice of which one to follow. That is the
same shape as the errors already fixed (手 савар, 面 сэнжтэй аяга, 軒 хөмсөг): the Mongolian
word was broad, the bridge picked a sense the Japanese word does not carry, and wrote all of
them down in the process.

**Most of these are correct.** A broad English list usually just means the Mongolian word is
broad. The list exists because each row can be settled at a glance, not because each is wrong.

The single-kanji rows are not here -- those were checked against the 1,550 kanji glosses and
the ten wrong ones are already fixed. These have no second witness, which is why they need an
eye.

To correct one, write the Mongolian in `tools/bridge-review.tsv`; leave it blank to keep what
is there. Ordered by how many senses the pivot was choosing between.
