## Posting in groups

- Post **as the Page**, not as yourself. In each group, check whether it lets Pages post. Some
  groups only allow personal profiles, and then it's your choice whether to post as yourself.
- Read each group's rules first. Many groups ban links or only allow them on certain days.
- **Don't paste the same post into many groups on the same day.** Admins remove it, Facebook can
  flag it as spam, and the study groups share a lot of members.
- The best way in is **answering a real question**. When someone asks what a word is in Japanese,
  reply with a dictionary link for that word, e.g. `https://khan-japanese.org/dictionary.html?q=ном`.
- **Before the first share:** paste each link into Facebook's Sharing Debugger
  (developers.facebook.com/tools/debug) and press **Scrape Again**, so Facebook shows the new
  Mongolian preview instead of the old English one.
